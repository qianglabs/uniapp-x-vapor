# CSS、尺寸、布局与裁切

## 兼容性判定

App 使用 CSS 子集。每次修改先核对“属性 + 值 + 单位 + 平台 + Vapor/拍平 + 目标版本”，再由实际编译和设备确认。官方页面示例可能对应 alpha 分支，不能自动代表本机正式版。[CSS 总览](https://doc.dcloud.net.cn/uni-app-x/css/)

## 本工程默认方案

| 需求            | 采用                                      | 避免                                 |
| --------------- | ----------------------------------------- | ------------------------------------ |
| 基本布局        | Flex，明确方向、尺寸、对齐                | 默认 Grid、浏览器技巧                |
| 全屏高度        | 根 `height: 100%` 或有约束的 Flex 链      | `vh/vw` 高度、百分比 min-height      |
| 剩余滚动区      | 父级明确尺寸，子级 Flex，必要时零收缩基准 | 每层 auto，内容把视口撑开            |
| 字号和行高      | 明确 `px`                                 | 文字尺寸跟随 rpx 产生不一致          |
| 圆角            | 普通 4/8/10/12px 等层级，圆形 999px       | Vapor App 的 rpx 圆角                |
| 背景位图        | 真实 image + 定位                         | URL 型 background-image              |
| 安全区          | 固定间距 + 独立占位节点                   | calc 固定值相加、env 旧方案          |
| 样式隔离        | 每个需样式节点独立 class                  | 父继承、标签选择器、关系选择器、deep |
| 角标/跨边缘装饰 | 外层预留空间，卡片与角标为兄弟            | 从有圆角/裁切的按钮内负定位越界      |

圆角 rpx 限制和背景图值限制在核对的官方页面中有明确说明；字号、独立 class 与目录样式体系属于来源项目规范。[圆角](https://uniapp.dcloud.net.cn/uni-app-x/css/border-radius)、[背景](https://doc.dcloud.net.cn/uni-app-x/css/background-image.html)

安全区结构示意（按目标版本核对变量支持）：

```vue
<view class="actions">
	<text class="actions_label">确认</text>
</view>
<view class="safe-area" />
```

```css
.actions {
  padding: 16px;
}
.actions_label {
  font-size: 16px;
  line-height: 22px;
}
.safe-area {
  height: var(--uni-safe-area-inset-bottom);
}
```

这是结构示例，不是经本次 App 编译的成品组件。

## 扁平类名与组件边界

用 `.card_title` 或编译后为独立类的 BEM 嵌套，不用 `.card .title`。父组件需要改变子组件外观时，使用已提供的 Prop、slot、customStyle；内部文字颜色不一定继承根节点颜色。曾通过 Navbar title 插槽解决白色标题，而不是修改公共库。

本工程不使用 UnoCSS/Tailwind，不引入 `virtual:uno.css`、构建插件和工具类预设。新工程的样式方案需独立决定；这不是 Vapor 永远不能使用样式工具的结论。

## 先理解盒子再改数值

- `rpx` 视觉稿尺寸、`px` API 阈值和物理像素日志必须转换到同一单位再比较。
- 横向滚动不仅要横排，还要内容宽于视口、条目不被压缩；必要时按数量/间距计算实际宽度。
- 图文对齐分别考虑整个内容组居中、首行对齐和图形自身的视觉偏差；不要用额外水平占位修复纵向错位。
- 文字换行先检查明确宽度、行数、文本流和自动高度。历史 `word-break` 在用户编译器告警后被移除，不能用另一个未经确认属性替换。
- 移除尾部文字后，容器 padding/margin 仍可能制造空滚动区域；检查整棵占位结构。
- 装饰图先核对源图比例，避免把“完整展示”误作允许 `aspectFill` 裁切。

## 测量与缓存

内容行可变高时，条数 × 估算高度不能代替原生测量。邀请记录历史问题最终用行节点的异步真实边界求和，再加尾部高度。`scrollHeight` 在不可滚动容器上不一定是想要的总内容高度。

异步测量绑定请求版本、记录 ID 序列、当前 tab 和卸载状态。缓存只保存稳定值与结果，不以进入响应式缓存前后的对象身份判断同一视图；此项目曾出现正确高度已缓存，却因对象身份比较失败退回旧估算。

验证包含：短/长文字、0/1/临界/多条数据、大字体、小屏、顶部导航占位、底部安全区和弹层首次打开。没有原生测量时，不声称已定位平台盒模型漏洞。
