# 排错方法与验证层级

## 根据证据找层

| 现象              | 先查                                        | 不能直接推断                 |
| ----------------- | ------------------------------------------- | ---------------------------- |
| 模板编译失败      | 插槽组合、列表结构、条件编译、生成阶段      | 一定是 CSS 或原生 SDK        |
| setup/type 未定义 | 绑定、字面量断言、类型展开、runtime props   | TS 解析过就一定正确          |
| 列表空白          | key 取数、空 Prop、加载状态、测量、容器边界 | 接口有数据就一定组件库有 bug |
| 原生崩溃          | 原始堆栈、线程、Build ID、最小触发差异      | catch 日志位置就是出错行     |
| 弹层首开空白      | 原生容器尺寸、实例轮次、插槽附着            | 加 nextTick/延时必然有效     |
| 点击无响应        | 命中层、受控状态、pending 锁、运行时 Prop   | 提高 z-index 就能解决        |
| 输入显示旧值      | 原生值、业务值、更新去重、编辑阶段          | ref 已更新就代表控件显示已变 |
| iOS 打包失败      | UTS 公共代码生成 Swift、异常/循环声明       | Android 成功即跨端成功       |
| 视频全屏后黑屏    | 节点/Surface 生命周期、尺寸、暂停帧         | 一定是网络/License           |

## 验证层级不可混写

| 层级                   | 可以说明                       | 不能说明                         |
| ---------------------- | ------------------------------ | -------------------------------- |
| 文档/格式检查          | 链接、格式、索引结构可读       | 示例能运行                       |
| 静态/语法检查          | 源码满足相应检查范围           | UTS 代码生成或 App 显示正确      |
| 纯逻辑模拟             | 指定输入下状态/边界处理正确    | 原生事件顺序、对象桥接、测量正确 |
| HBuilderX/UTS/原生编译 | 指定目标和工具链生成通过       | 包含完整宿主能力或设备可用       |
| 打包/包内容检查        | 资源/清单/类/SO 符合同次产物   | 已安装、权限/编解码正常          |
| 真机验证               | 指定设备、系统、基座和场景结果 | 所有设备/版本都通过              |

普通 JS 模拟曾遗漏响应式对象身份、原生控件值去重、旧基座字段缺失和真实 scrollHeight。测试输入要包括边界与版本差异，不能只把实现公式再抄一遍作为证明。

## 辅助搜索

按任务范围执行，命中后人工检查平台隔离与用途，不把任何命中都判成错误：

```powershell
rg -n --glob '*.uvue' '@(loadeddata|loadedmetadata|canplay)' pages components
rg -n 'uni\.request' pages components composables api
rg -n --glob '*.uvue' 'scroll-x|scroll-y|:deep\(|>>>' pages components
rg -n --glob '*.uvue' 'background-image|\b(vh|vw)\b|safe-area-inset-bottom' pages components
```

跨行 CSS、模板上下文与 UTS 类型不能靠简单正则全面验证。生成物允许只读看 runtime props、桥接代码和错误定位，不修改、提交生成代码。

## 真机最小矩阵

- 列表：0/1/多条、首开、连续刷新、分页失败恢复、乱序、筛选、头插、滚动返回。
- 弹层：首开/重开、关闭中打开、父子切换、返回键、键盘、离场后点击页面。
- 视频：图片混排、快速切页、页面隐藏返回、全屏、失败/重试、播放命令交接。
- 原生：权限拒绝/部分授权/设置页返回、无扩展名资源、路径转换、取消、卸载后回调。
- 剪辑启用时：导入、拖动/裁切/排序、音频/转场、撤销重做、全屏、导出/取消、重复进入和释放。
- 账号/支付：切会话后迟到响应、断线恢复、支付返回回查、重复通知、返回栈。

覆盖实际目标平台。Harmony 和小程序没有本次设备证据，不因代码存在条件分支而标为支持。

## 命令与清理

先确认 package/scripts 和工具，禁止凭习惯运行不存在的 pnpm build/test。来源工程当前无根 package.json，运行/发行依赖 HBuilderX，不能为知识包整理虚构构建成功。

只格式化本次文件，沿用源工程配置。临时验证脚本与产物验证后删除；不删除现有脚本和用户文件。若工具缺失，说明实际替代检查，不能把失败尝试写成通过。

根因记录包含任务、表现、证据、根因边界、处理、预防、实际验证和关联文件。相似问题先搜索旧记录；中间方案已被后续修正时，以最终方案为准，原始记录保留演进。
