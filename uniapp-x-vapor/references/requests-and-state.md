# 请求契约、会话、Socket 与业务状态

## 契约先于界面字段

先查端点 URL、method、query/body、返回层级、分页语义、字段大小写/可空性，再结合实际响应和当前调用方建模。来源工程 `docs/api-map.md` 是完整接口定位入口，但文档不等于本次真实响应，更不能把模型全部字段搬进业务。

`SkipCount` 等名称不能代替分页语义：本项目订单曾实际使用页序号而误按跳过条数处理。每个端点核对起始页、增量、total 和结束条件，不把其他接口的规则当默认。

页面 → 领域 API → 唯一请求层。来源工程为 `utils/request.uts` 基于 kux-request；不新增平行 token、错误提示、刷新 token 或防重复提交封装。

## 边界归一化

- 普通文本、URL 和流式内容不是 JSON 对象，不能一律 JSON.parse。
- `"false"` 是字符串，不能靠泛型声明或真假判断当布尔；已确认文本布尔在领域 API 严格转换，未知内容进入错误态。
- 空字符串有时代表单对象无数据，先映射 null，不能强转对象后传必填 Prop。
- 仅在确有 UTS 结构转换需求的边界使用 JSON 转换并解释原因；已具名响应直接使用，不给页面添加 stringify/parse 克隆。
- 通用请求层可能为已知响应信封处理多个 code/message 位置，这与业务层猜字段别名不是同一事；不复制该容错到每个页面。

## 竞态和单次操作

异步结果在写入数据、错误、loading 之前都检查“仍是当前请求/会话且未卸载”。仅给数据加版本判断，但旧 finally 又关闭新 loading，同样会出错。

请求状态至少分清：initial、loading、refreshing、loadingMore、success、empty、error。可以用具名状态或独立字段，但避免同一个布尔承担多种行为。

失败不递增页码、不清已有数据、不永久保留提交锁。并发相同提交的集合只覆盖在途请求，finally 释放，允许立即重试；不要用固定时间防重让失败后无法点击。

catch 应进行错误态恢复、降级、验证码重置或流程回退。只日志后吞掉异常不是业务处理；仅复位 loading/锁使用 finally，并注意当前版本归属。

## 登录与账号切换

会话变化增加版本，使旧请求、token 刷新和临时交接失效。清理用户级缓存、Socket 和操作状态，不能让 A 账号结果写入 B 账号。

全局已保证鉴权的页面不重复维护访客 UI，但新工程必须先确认存在这条入口保证。账号添加成功若用户要求留在当前选择页，更新会话和列表、收起登录覆盖层，保留原返回栈；不要 reLaunch 丢栈再伪造返回。

## 验证码与页面恢复

倒计时以截止时间为事实，而非隐藏时将剩余秒数清零。来源工程在当前登录会话按手机号共享发送截止时间、已发送标记和在途 Promise；隐藏暂停 UI 时钟并清敏感输入，重开按真实时间恢复。成功使用后标记已使用但保留发送冷却。不要存储短信码/密码以恢复页面。

## 跨页结果交接

入口已请求的结果可以按会话版本一次性交给详情页，消费即清；直接进入、后续返回和重试仍回查。跳转失败清交接数据并提供反馈。不能把一次优化做成永久缓存，从而显示陈旧资料。

## Socket 和任务恢复

来源工程将 SignalR 传输放 `utils/signalr.uts`，领域分发放 Store。通用经验是分离协议与业务，不把 Socket Store 变成所有功能入口。

SignalR JSON 帧按 Record Separator 0x1E 分隔；握手、Invocation、未知事件分开处理，ArrayBuffer 按目标平台支持的 UTF-8 路径解码。服务端别名在适配层统一。断线重连使用连接版本，主动停止取消重连；token/隐私许可存在后才连接。

Socket 是加速通道，详情回查是恢复路径。回前台、丢事件、重连和支付返回时按任务/订单 ID 回查；终态具备幂等性。未知进度、生成成功、结果地址尚未就绪是可区分状态。

不记录带 access_token 的完整连接地址、上传签名或完整私有 URL。

## 动态工作流与权限语义

来源工程按已确认输入分类赋值：视频 `value/coverUrl`；AiSystemPrompt 按契约处理 `value/url/displayValue/coverUrl`；图片/图片列表及普通参数仅修改各自 `value`。不得按用户选中的媒体类型改变服务端参数结构，不能把封面塞进文本 displayValue。

权限、身份、套餐购买和免费试用字段彼此独立。历史 `canFreeTrial` 展示不能额外附带 accessRequirement；会员身份不能从套餐 isPurchased 或文案猜测。目标工程必须采用自己的契约，不复制这些业务字段为框架模型。

详情字段优先级按契约区分“缺失”和“明确 null”，不能被列表兜底无条件覆盖。携带目标 ID 初始化失败时不要悄悄选第一项，避免替用户提交到错误对象。
